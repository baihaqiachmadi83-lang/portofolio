[ 01 ] PROFILE // TENTANG SAYA

Tentang Saya

Memadukan pemahaman pedagogi bahasa dengan perancangan produk digital dan eksplorasi teknologi AI.

Saya adalah lulusan Pendidikan Bahasa Inggris dari Universitas Nahdlatul Ulama Yogyakarta, Indonesia. Saya memiliki ketertarikan pada pengajaran bahasa Inggris, pengembangan media pembelajaran digital, teknologi pendidikan, dan pemanfaatan AI dalam proses pembelajaran.

Melalui kegiatan akademik dan pengembangan proyek, saya mengeksplorasi bagaimana teknologi dapat membantu menjawab kebutuhan pembelajaran, khususnya bagi peserta didik pendidikan nonformal (Paket C).

Saya tertarik pada peluang yang memungkinkan saya menggabungkan pemahaman pendidikan, pemecahan masalah, pengembangan konten, riset, dan inovasi digital.

Pondasi Pedagogi yang Terstruktur

Penyusunan alur pembelajaran bertahap (scaffolding), kejelasan instruksi tata bahasa, dan rancangan materi yang berbasis pada kebutuhan siswa.

Aksesibilitas Pendidikan Nonformal

Perancangan media pembelajaran berbasis mobile yang ringan, efisien kuota, dan responsif untuk peserta didik Paket C.

Integrasi AI Berpusat pada Pengguna

Pemanfaatan AI sebagai alat bantu riset, akselerasi prototipe instruksional, dan pemetaan materi yang relevan.

[ 03 ] WORKS // PROYEK UNGGULAN

Proyek Unggulan

Media pembelajaran dan rancangan materi instruksional berorientasi pada peserta didik Paket C dan pendidikan nonformal.

PROJECT 01 Konsep & Prototipe Riset

Mobile-Based E-Learning Module for Simple Present Tense

Konteks: PKBM Tunas Mandiri, Wonosobo, Jawa Tengah
Ringkasan Masalah

Peserta didik Paket C di PKBM Tunas Mandiri memiliki keterbatasan waktu tatap muka dan membutuhkan bimbingan intensif untuk memahami Simple Present Tense secara mandiri.

Tujuan Proyek

Merancang media pembelajaran tata bahasa berbasis mobile yang terstruktur untuk mendukung pembelajaran mandiri melalui penyampaian konsep bertahap dan latihan interaktif.

Kontribusi Pribadi

Penyusunan alur instruksional, perancangan aktivitas latihan mandiri, pemetaan skenario evaluasi, dan pengembangan konten digital berbasis mobile.

Pendekatan & Alat yang Digunakan
Instructional Scaffolding Mobile Learning Framework Grammar Drill Design Digital Media Development

PROJECT 02 Live Web Application

MANTUL — Mobile Access for Nonformal Teaching and Ubiquitous Learning

Inisiatif Pembelajaran Berbasis Mobile untuk Peserta Didik Paket C
Ringkasan Masalah

Peserta didik nonformal membutuhkan aplikasi belajar yang ramah spesifikasi perangkat, hemat kuota, dan fleksibel dibuka di mana saja.

Tujuan Proyek

Menyediakan media belajar mandiri komprehensif mencakup Vocabulary, Speaking, Reading, dan Grammar dengan alur unit bertahap, streak progres, dan mekanisme pendampingan tutor.

Kontribusi Pribadi

Perancangan konsep kurikulum mobile Paket C, penataan alur pembelajaran, perancangan antarmuka responsif mobile-first, dan implementasi penyimpanan progres lokal.

Teknologi yang Digunakan
